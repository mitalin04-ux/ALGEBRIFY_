About the Course

Build Solid Mathematical Foundations.

Linear Algebra is the language of higher mathematics and computational science. This course introduces each concept progressively—starting from basic definitions and numerical examples, and advancing to abstract vector spaces, inner products, and canonical forms.

Curriculum

10 Complete Learning Modules

Follow a structured 10-module syllabus covering the full breadth of linear algebra with textbook-level clarity, complete definitions, worked numerical examples, and interactive tools.

Module 01

Algebra of Matrices

Matrix definition, order, 10 types of matrices, matrix equality, addition, scalar multiplication, matrix multiplication, and transpose.

Start Module 1
Module 02

Systems of Linear Equations

Homogeneous and non-homogeneous systems, augmented matrices, triangular and echelon forms, Gaussian & Gauss-Jordan elimination, and consistency.

Start Module 2
Module 03

Field

Definition of a field and field axioms, real numbers $\mathbb{R}$, complex numbers $\mathbb{C}$, and Galois Field $\text{GF}(2)$ arithmetic.

Start Module 3
Module 04

Vectors

Geometric and algebraic vectors, vector addition, scalar multiplication, dot product and its properties, and 3D cross product.

Start Module 4
Module 05

Vector Spaces

Vector space axioms, linear combinations, span, subspaces, row and column spaces, linear independence, basis, and dimension.

Start Module 5
Module 06

Linear Transformations

Definition of linear mappings, kernel (null space), image (range), rank, nullity, and the Rank-Nullity Dimension Theorem.

Start Module 6
Module 07

Linear Transformations & Matrices

Matrix representation with respect to bases, standard matrix $[T]$, change of basis transition matrices, and matrix similarity.

Start Module 7
Module 08

Inner Product Spaces & Orthogonality

Inner products, induced norm, Cauchy-Schwarz inequality, orthogonal and orthonormal sets, and the Gram-Schmidt process.

Start Module 8
Module 09

Determinants

Determinants of square matrices, Laplace cofactor expansion, determinant algebraic properties, Cramer's Rule, and matrix invertibility.

Start Module 9
Module 10

Diagonalization & Eigenvalues

Characteristic polynomials, eigenvalues, eigenvectors, Cayley-Hamilton theorem, minimal polynomials, diagonalization, and Jordan form.

Start Module 10
