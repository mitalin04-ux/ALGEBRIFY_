Module 05

Vector Spaces

A vector space is an abstract mathematical universe whose elements (called vectors) can be added together and multiplied by scalars while satisfying 10 fundamental algebraic axioms. In this module, you will explore abstract vector spaces, subspaces, span, linear independence, basis, and dimension.

Read Lesson Independence Checker Practice Quiz

Learning Objectives

  • State the 10 formal axioms defining a vector space $V$ over a field $F$.
  • Apply the 3-step subspace test to determine whether a subset is a subspace.
  • Define linear combinations, span, row space, and column space of a matrix.
  • Test a set of vectors for linear independence using matrix rank or determinants.
  • Find a basis and determine the dimension of a vector space and its subspaces.
Section 5.1

Definition of a Vector Space and the 10 Axioms

Let $F$ be a field (such as $\mathbb{R}$). A vector space over $F$ is a non-empty set $V$ equipped with two operations—vector addition ($+: V \times V \to V$) and scalar multiplication ($\cdot: F \times V \to V$)—that satisfy the following 10 axioms for all $\mathbf{u}, \mathbf{v}, \mathbf{w} \in V$ and scalars $c, d \in F$:

Vector Addition Axioms

  • 1. Closure under Addition: $\mathbf{u} + \mathbf{v} \in V$.
  • 2. Commutativity: $\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$.
  • 3. Associativity: $(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$.
  • 4. Zero Vector: There exists $\mathbf{0} \in V$ such that $\mathbf{u} + \mathbf{0} = \mathbf{u}$.
  • 5. Additive Inverse: For each $\mathbf{u}$, there exists $(-\mathbf{u}) \in V$ such that $\mathbf{u} + (-\mathbf{u}) = \mathbf{0}$.

Scalar Multiplication Axioms

  • 6. Closure under Scalar Mult: $c\mathbf{u} \in V$.
  • 7. Scalar Distributivity: $c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$.
  • 8. Vector Distributivity: $(c + d)\mathbf{u} = c\mathbf{u} + d\mathbf{u}$.
  • 9. Associativity of Scalars: $(cd)\mathbf{u} = c(d\mathbf{u})$.
  • 10. Multiplicative Identity: $1\mathbf{u} = \mathbf{u}$.

Standard Examples of Vector Spaces

  • $\mathbb{R}^n$: Ordered $n$-tuples of real numbers with component-wise operations.
  • $P_n(\mathbb{R})$: All polynomials of degree $\le n$, with standard polynomial addition.
  • $M_{m \times n}(\mathbb{R})$: All $m \times n$ matrices under matrix addition and scalar multiplication.
Section 5.2

Subspaces and the 3-Step Subspace Test

Definition of a Subspace:

A non-empty subset $W$ of a vector space $V$ is called a subspace of $V$ if $W$ is itself a vector space under the same addition and scalar multiplication defined on $V$.

The 3-Step Subspace Test: To prove that a subset $W \subseteq V$ is a subspace, we only need to verify 3 simple conditions:

  1. Zero Vector: The zero vector must belong to $W$ ($\mathbf{0} \in W$).
  2. Closed under Addition: If $\mathbf{u}, \mathbf{v} \in W$, then $\mathbf{u} + \mathbf{v} \in W$.
  3. Closed under Scalar Multiplication: If $c \in F$ and $\mathbf{u} \in W$, then $c\mathbf{u} \in W$.
Example

Testing a Plane in $\mathbb{R}^3$ for Subspace Properties

Is the set $W = \left\{ \begin{bmatrix} x \\ y \\ z \end{bmatrix} \in \mathbb{R}^3 : 2x - 3y + z = 0 \right\}$ a subspace of $\mathbb{R}^3$?

Verification:

  1. Zero vector: $2(0) - 3(0) + 0 = 0 \implies \mathbf{0} \in W$ (holds).
  2. Addition: For $\mathbf{u}, \mathbf{v} \in W$, $2(u_1+v_1) - 3(u_2+v_2) + (u_3+v_3) = (2u_1-3u_2+u_3) + (2v_1-3v_2+v_3) = 0 + 0 = 0 \implies \mathbf{u}+\mathbf{v} \in W$ (holds).
  3. Scalar multiplication: $2(cu_1) - 3(cu_2) + (cu_3) = c(2u_1 - 3u_2 + u_3) = c(0) = 0 \implies c\mathbf{u} \in W$ (holds).

Conclusion: Yes, $W$ is a valid 2-dimensional subspace (a plane passing through the origin).

Section 5.3

Span, Linear Independence, Basis & Dimension

1. Span of Vectors

The set of all possible linear combinations formed by vectors $S = \{\mathbf{v}_1, \dots, \mathbf{v}_k\}$:

\[ \text{Span}(S) = \{c_1\mathbf{v}_1 + \dots + c_k\mathbf{v}_k : c_i \in F\} \]

The span of any set of vectors is automatically a valid subspace of $V$.

2. Linear Independence

A set of vectors $\{\mathbf{v}_1, \dots, \mathbf{v}_k\}$ is linearly independent if:

\[ c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \dots + c_k\mathbf{v}_k = \mathbf{0} \implies c_1 = c_2 = \dots = c_k = 0 \]

If non-trivial scalars exist, the vectors are linearly dependent.

3. Basis of a Vector Space

A set of vectors $B = \{\mathbf{v}_1, \dots, \mathbf{v}_n\}$ is a basis for $V$ if:

  1. $B$ is linearly independent.
  2. $B$ spans $V$ ($\text{Span}(B) = V$).
\[ B \text{ is linearly independent and } \text{Span}(B) = V \]

4. Dimension ($\dim(V)$)

The number of vectors in any basis of vector space $V$:

\[ \dim(\mathbb{R}^n) = n, \quad \dim(P_n) = n + 1, \quad \dim(M_{m \times n}) = m \times n \]

All bases of a finite-dimensional space have the exact same size.

Key Points

  • A subspace must always contain the zero vector ($\mathbf{0} \in W$).
  • To test linear independence, set up $A\mathbf{c} = \mathbf{0}$; if $\det(A) \neq 0$ (or rank is maximal), the vectors are independent.
  • A basis is a minimal spanning set and a maximal linearly independent set.
  • The dimension of $\mathbb{R}^3$ is 3; any basis of $\mathbb{R}^3$ must have exactly 3 independent vectors.

Common Mistakes

  • A line or plane that does not pass through the origin (e.g. $2x + y = 5$) is NOT a subspace because $\mathbf{0} \notin W$.
  • Any set containing the zero vector ($\mathbf{0}$) is always linearly dependent.
  • In $\mathbb{R}^n$, any set with more than $n$ vectors is automatically linearly dependent.
