Module 06

Linear Transformations

A linear transformation is a structure-preserving function between vector spaces that preserves addition and scalar multiplication. In this module, you will master the formal algebraic definitions of linear mappings, study Kernel (Null Space) and Image (Range), and prove the cornerstone Rank-Nullity Dimension Theorem.

Read Lesson Matrix Explorer Practice Quiz

Learning Objectives

  • State the definition and the two linearity conditions for a mapping $T: V \to W$.
  • Identify examples of linear mappings including matrix mappings, derivative operators, and projections.
  • Define Kernel ($\text{Ker}(T)$), Image ($\text{Im}(T)$), Nullity, and Rank.
  • State and apply the fundamental Rank-Nullity Dimension Theorem ($\text{Nullity} + \text{Rank} = \dim(V)$).
  • Perform algebraic operations on linear mappings (addition, scalar multiplication, composition).
Section 6.1

Definition of a Linear Transformation

Let $V$ and $W$ be two vector spaces over the same field $F$. A function $T: V \to W$ is called a linear transformation (or linear mapping) if it satisfies two conditions for all vectors $\mathbf{u}, \mathbf{v} \in V$ and every scalar $c \in F$:

The Two Linearity Axioms:
  1. Additivity: $T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})$
  2. Homogeneity (Scalar Scaling): $T(c\mathbf{u}) = c T(\mathbf{u})$

Combining both conditions into a single statement: \[ T(c_1\mathbf{u} + c_2\mathbf{v}) = c_1 T(\mathbf{u}) + c_2 T(\mathbf{v}) \]

Direct Properties of Linear Transformations

  • Zero Vector Property: $T(\mathbf{0}_V) = \mathbf{0}_W$. (A linear mapping must always map origin to origin).
  • Negation Property: $T(-\mathbf{v}) = -T(\mathbf{v})$.
  • Linear Combinations: $T\left(\sum_{i=1}^k c_i \mathbf{v}_i\right) = \sum_{i=1}^k c_i T(\mathbf{v}_i)$.
Section 6.2

Standard Examples of Linear Transformations

1. Matrix Mapping

Let $A$ be an $m \times n$ matrix. The function $T: \mathbb{R}^n \to \mathbb{R}^m$ defined by $T(\mathbf{x}) = A\mathbf{x}$ is linear because $A(\mathbf{u}+\mathbf{v}) = A\mathbf{u}+A\mathbf{v}$ and $A(c\mathbf{u}) = cA\mathbf{u}$.

2. Derivative Operator

Let $D: P_n(\mathbb{R}) \to P_{n-1}(\mathbb{R})$ be the differentiation map $D(p(x)) = p'(x)$. Since $(f+g)' = f'+g'$ and $(cf)' = c f'$, differentiation is linear.

3. Zero Transformation

The mapping $T_0: V \to W$ defined by $T_0(\mathbf{v}) = \mathbf{0}_W$ for all $\mathbf{v} \in V$ is trivially linear.

4. Identity Transformation

The mapping $I_V: V \to V$ defined by $I_V(\mathbf{v}) = \mathbf{v}$ for all $\mathbf{v} \in V$ is linear.

Section 6.3

Kernel (Null Space), Image (Range) & Rank-Nullity Theorem

1. Kernel ($\text{Ker}(T)$ / Null Space)

The set of all vectors in domain $V$ that map to the zero vector in $W$:

\[ \text{Ker}(T) = \{\mathbf{v} \in V : T(\mathbf{v}) = \mathbf{0}_W\} \]

$\text{Ker}(T)$ is always a subspace of $V$.
Nullity: $\text{Nullity}(T) = \dim(\text{Ker}(T))$.
Injectivity: $T$ is one-to-one (injective) $\iff \text{Ker}(T) = \{\mathbf{0}\}$.

2. Image ($\text{Im}(T)$ / Range)

The set of all image vectors in codomain $W$ produced by $T$:

\[ \text{Im}(T) = \{T(\mathbf{v}) : \mathbf{v} \in V\} \]

$\text{Im}(T)$ is always a subspace of $W$.
Rank: $\text{Rank}(T) = \dim(\text{Im}(T))$.
Surjectivity: $T$ is onto (surjective) $\iff \text{Im}(T) = W$.

The Fundamental Rank-Nullity Dimension Theorem:

If $V$ is a finite-dimensional vector space and $T: V \to W$ is a linear transformation, then:

\[ \dim(\text{Ker}(T)) + \dim(\text{Im}(T)) = \text{Nullity}(T) + \text{Rank}(T) = \dim(V) \quad (\text{Dimension of Domain}) \]
Worked Example

Applying the Rank-Nullity Theorem

Let $T: \mathbb{R}^4 \to \mathbb{R}^3$ be a linear transformation defined by $T(\mathbf{x}) = A\mathbf{x}$ where the rank of $A$ is 2. Find the nullity of $T$.

Solution:

  1. Dimension of the domain $V = \mathbb{R}^4$ is $\dim(V) = 4$.
  2. $\text{Rank}(T) = \dim(\text{Im}(T)) = 2$.
  3. By the Rank-Nullity Theorem: $\text{Nullity}(T) + \text{Rank}(T) = 4 \implies \text{Nullity}(T) + 2 = 4 \implies \text{Nullity}(T) = \mathbf{2}$.
Section 6.4

Algebra of Linear Transformations

1. Sum ($T_1 + T_2$)

\[ (T_1 + T_2)(\mathbf{v}) = T_1(\mathbf{v}) + T_2(\mathbf{v}) \]

The sum of two linear mappings from $V \to W$ is also a linear mapping from $V \to W$.

2. Scalar Multiple ($cT$)

\[ (cT)(\mathbf{v}) = c \cdot T(\mathbf{v}) \]

Scaling a linear mapping produces another valid linear mapping.

3. Composition ($T_1 \circ T_2$)

\[ (T_1 \circ T_2)(\mathbf{u}) = T_1(T_2(\mathbf{u})) \]

If $T_2: U \to V$ and $T_1: V \to W$, their composition is a linear mapping $T_1 \circ T_2: U \to W$.

The Vector Space $\mathcal{L}(V, W)$

The set of all linear transformations from $V$ to $W$, denoted by $\mathcal{L}(V, W)$ or $\text{Hom}(V, W)$, forms a vector space under transformation addition and scalar multiplication. If $\dim(V) = n$ and $\dim(W) = m$, then $\dim(\mathcal{L}(V, W)) = m \times n$.

Key Points

  • $T$ is linear $\iff T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u})+T(\mathbf{v})$ and $T(c\mathbf{u}) = cT(\mathbf{u})$.
  • $\text{Ker}(T) \subseteq \text{Domain}$; $\text{Im}(T) \subseteq \text{Codomain}$.
  • $\text{Nullity}(T) + \text{Rank}(T) = \dim(\text{Domain})$.
  • $T$ is one-to-one (injective) $\iff \text{Ker}(T) = \{\mathbf{0}\}$ (Nullity = 0).

Common Mistakes

  • A mapping with a constant offset like $T(x) = 2x + 3$ is NOT a linear transformation because $T(0) = 3 \neq 0$. (It is an affine map).
  • Do not sum the codomain dimension in the Rank-Nullity theorem; it is always equal to the domain dimension $\dim(V)$.
