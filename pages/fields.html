Module 03

Field

In linear algebra, scalars do not have to be ordinary real numbers. A field is an algebraic structure where addition, subtraction, multiplication, and division (except by zero) behave with the same familiar rules as standard arithmetic.

Read Lesson Field Explorer Practice Quiz

Learning Objectives

  • State the formal definition and the 11 algebraic axioms of a field $(F, +, \cdot)$.
  • Identify examples of fields: Real numbers $\mathbb{R}$, Complex numbers $\mathbb{C}$, and Galois Field $\text{GF}(2)$.
  • Explain why the set of integers $\mathbb{Z}$ is NOT a field.
  • Perform addition, multiplication, and find inverses in $\mathbb{C}$ and $\text{GF}(2)$.
  • Apply cancellation laws and the zero-divisor property ($ab = 0 \implies a = 0$ or $b = 0$).
Section 3.1

Definition of a Field and the 11 Axioms

A field is a set $F$ equipped with two binary operations called addition ($+$) and multiplication ($\cdot$) that satisfy the following 11 axioms for all elements $a, b, c \in F$:

Axioms for Addition ($+$)

  • 1. Closure: $a + b \in F$.
  • 2. Associativity: $(a + b) + c = a + (b + c)$.
  • 3. Commutativity: $a + b = b + a$.
  • 4. Additive Identity: There exists an element $0 \in F$ such that $a + 0 = a$.
  • 5. Additive Inverse: For every $a \in F$, there exists $(-a) \in F$ such that $a + (-a) = 0$.

Axioms for Multiplication ($\cdot$)

  • 6. Closure: $a \cdot b \in F$.
  • 7. Associativity: $(a \cdot b) \cdot c = a \cdot (b \cdot c)$.
  • 8. Commutativity: $a \cdot b = b \cdot a$.
  • 9. Multiplicative Identity: There exists $1 \in F$ ($1 \neq 0$) such that $a \cdot 1 = a$.
  • 10. Multiplicative Inverse: For every $a \neq 0$, there exists $a^{-1} = \frac{1}{a} \in F$ such that $a \cdot a^{-1} = 1$.
11. Distributive Law of Multiplication over Addition:
\[ a \cdot (b + c) = a \cdot b + a \cdot c \quad \text{for all } a, b, c \in F \]
Section 3.2

Standard Examples of Fields

1. Real Numbers ($\mathbb{R}$)

The standard continuous number line. Satisfies all 11 axioms under ordinary addition and multiplication.

\[ 5 + (-5) = 0, \quad 4 \cdot \frac{1}{4} = 1 \]

2. Complex Numbers ($\mathbb{C}$)

Numbers of the form $z = a + bi$ where $i^2 = -1$ and $a, b \in \mathbb{R}$.

\[ z^{-1} = \frac{a - bi}{a^2 + b^2} \quad (z \neq 0) \]

3. Rational Numbers ($\mathbb{Q}$)

All fractions of integers $\frac{p}{q}$ ($q \neq 0$). Fully closed under addition, subtraction, multiplication, and non-zero division.

\[ \left(\frac{p}{q}\right)^{-1} = \frac{q}{p} \quad (p \neq 0) \]

4. Galois Field ($\text{GF}(2) = \mathbb{Z}_2$)

The smallest finite field consisting of only two elements: $\{0, 1\}$. Operations are performed modulo 2.

\[ 1 + 1 = 0, \quad 1 \cdot 1 = 1 \]

Why is the Set of Integers $\mathbb{Z}$ NOT a Field?

While the integers $\mathbb{Z} = \{\dots, -2, -1, 0, 1, 2, \dots\}$ satisfy 10 of the axioms, they fail Axiom 10 (Multiplicative Inverses). For example, for the non-zero integer $2 \in \mathbb{Z}$, its multiplicative inverse is $\frac{1}{2}$, which is not an integer ($\frac{1}{2} \notin \mathbb{Z}$). Therefore, $\mathbb{Z}$ is an integral domain/ring, but not a field.

Section 3.3

Operations in $\mathbb{C}$ and Galois Field $\text{GF}(2)$

Arithmetic in Galois Field $\text{GF}(2)$

In $\text{GF}(2) = \{0, 1\}$, addition corresponds to the logical XOR operation and multiplication corresponds to the logical AND operation:

Addition Table ($+$ mod 2)

+ 0 1
0 0 1
1 1 0

Note: $1 + 1 = 0 \implies -1 = 1$.

Multiplication Table ($\cdot$ mod 2)

· 0 1
0 0 0
1 0 1

$1^{-1} = 1$.

Worked Example

Complex Number Multiplicative Inverse

Find the multiplicative inverse of $z = 3 + 4i \in \mathbb{C}$.

Step-by-Step Solution:

\[ z^{-1} = \frac{1}{3 + 4i} = \frac{1 \cdot (3 - 4i)}{(3 + 4i)(3 - 4i)} = \frac{3 - 4i}{3^2 - (4i)^2} = \frac{3 - 4i}{9 - (-16)} = \frac{3 - 4i}{25} = \frac{3}{25} - \frac{4}{25}i \]

Verification: $(3 + 4i)\left(\frac{3}{25} - \frac{4}{25}i\right) = \frac{9 - 12i + 12i + 16}{25} = \frac{25}{25} = 1$.

Key Points

  • A field requires all 11 axioms: addition and multiplication are abelian groups, with distributivity.
  • Every non-zero element in a field must have a multiplicative inverse ($a^{-1} = \frac{1}{a}$).
  • $\mathbb{R}, \mathbb{C}, \mathbb{Q},$ and $\text{GF}(2)$ are valid fields.
  • In any field, $ab = 0 \implies a = 0$ or $b = 0$ (no zero-divisors).

Common Mistakes

  • Do not confuse integers ($\mathbb{Z}$) with fields; integers lack multiplicative inverses.
  • In $\text{GF}(2)$, remember that $1 + 1 = 0$ (subtraction and addition are identical).
  • Division by zero ($0^{-1}$) is never defined in any field.
